

### EastNine GitHub Search MCP Server
📁 **디렉토리**: `eastnine-github-search/`

GitHub 저장소에서 스크립트를 자연어로 검색할 수 있는 MCP 서버입니다.

**주요 기능:**
- 🔍 자연어 검색 (예: "파일 압축하는 스크립트", "데이터베이스 백업 도구")
- 📁 개인 GitHub 저장소 전용 검색
- 🎯 스크립트 파일 자동 감지
- 📖 스크립트 내용 조회
- ⚡ 빠른 검색 및 관련성 점수 제공

**사용법:**
```bash
cd eastnine-github-search
pip install -e .
```
