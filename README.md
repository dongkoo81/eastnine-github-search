# MCP (Model Context Protocol) Projects

이 저장소는 다양한 MCP 서버 프로젝트들을 포함하고 있습니다.

## 프로젝트 목록

### 1. EastNine GitHub Search MCP Server
📁 **디렉토리**: `eastnine-github-search/`

GitHub 저장소에서 스크립트를 자연어로 검색할 수 있는 MCP 서버입니다.

**주요 기능:**
- 🔍 자연어 검색 (예: "파일 압축하는 스크립트", "데이터베이스 백업 도구")
- 📁 개인 GitHub 저장소 전용 검색
- 🎯 스크립트 파일 자동 감지
- 📖 스크립트 내용 조회
- ⚡ 빠른 검색 및 관련성 점수 제공

**사용법:**
```bash
cd eastnine-github-search
pip install -e .
```

자세한 내용은 [eastnine-github-search/README.md](./eastnine-github-search/README.md)를 참조하세요.

## MCP (Model Context Protocol)란?

MCP는 애플리케이션이 LLM에 컨텍스트를 제공하는 방법을 표준화하는 오픈 프로토콜입니다. 로컬에서 실행되는 MCP 서버와의 통신을 통해 AI 어시스턴트의 기능을 확장할 수 있습니다.
